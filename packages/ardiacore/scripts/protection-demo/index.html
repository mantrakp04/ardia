What this test proves

Each sample is counted once. “Clicked” requires both a successful visit recorded by AdNauseam and its request intercepted locally. The scheduler runs at its normal speed; the first click can take a minute. The sample ad frame and tracker use explicit local fixture rules. Pausing the stream only stops new samples, not already queued visits.

GPC is checked in page JavaScript and an HTTP header. CNAME uncloaking, link cleaning, malware filter lists and site cleanup show configuration, not a comprehensive protection test. Secure DNS, HTTPS upgrades and fingerprinting protections inherited from Helium are not measured here. Use this lab in a normal window of the demo’s default profile. This page never changes your protection mode.
