# 0.2.42 → 0.2.43 release gate

0.2.43 collects nightlies 1 to 9 and moves the engine to Chromium 156.0.8078.79 on Helium 0.20.3: Glass or Classic, the Dia-order right-click menus, the sidebar player, Memory Saver, profile icons, the bookmarks bar's drag and drop, per-tab mute, the zoom panel, the compact toolbar, Peek from pinned tabs, and the blank-flash fix on tab switch. 0.2.42 is native API 21 and 0.2.43 is 35, so the control ran its own bench bundle, built from `git archive v0.2.42` (`dist/0.2.42/bench/main.jsbundle`). RC1 is CI's dry run of ce5eb74a (build 96). Measured on 2026-10-31, interleaved, on AC.

The perf harness had drifted from the app over the nine nightlies; 34be6a9f and 3a25b9fd bring it up to 0.2.43's tree while still reading 0.2.42's state, so both apps run the same scenarios.

## Ratchet

RC1 went over on 33 counts in both runs, each placed against 0.2.42's export running the same scenarios and raised by reason in 3da8ee50; 44 ceilings were lowered. One was a fan-out to fold back: 781cdc76e's per-tab mute gave every TabRow and PinnedTile its own `useMuteState` selector on every store update (switchTabs selector calls 27015 → 33466, pageLoad +9705). bebc866e moves the row's mute state into the flags word `useRowState` already reads. The rest are the features' own components: the right-click menu areas, one `TabPressArea` per tab surface, the compact toolbar's and bookmarks bar's settings selectors, Glass's theme selector, the zoom panel and the new onLayout views.

## JS

RC1, 3 alternating rounds, each app on its own bundle. Separated and worse beyond render counts: typing30.listenerMs 0.6 [0.5–0.6] → 3.6 [3.2–3.8], startup.launchToFirstWindowMs 2908 → 3001, open20.taskMs 800 → 833.

- **typing30.listenerMs** was the favicons store's one listener (0.36 → 2.83 ms over the same 18 updates). Since 8a4051773 it diffed every watched page on each update instead of a touched set; timed in the app, that scan over ~195 watched pages took 0.08–0.19 ms per update in Hermes. 73688848 has the hot writers (lookup answers, remembered and adopted icons) record the pages they wrote, and the listener checks only those pages' watchers; a write without a record falls back to the scan.
- **startup** and **open20** are the features' renders (startup renders 638 → 726, open renders 6164 → 6510; the ratchet's list above). launchToFirstWindowMs and open20.taskMs overlap in the gate below; startup.taskMs (202 → 217 ms) and open20.otherJsMs (475 → 500 ms) stay apart. The native launch rows, the ones a user waits on, are the same as 0.2.42's.
