# 0.2.40 → 0.2.41 release gate

0.2.41 collects nightlies 1 to 6: Chromium 156 with Helium 0.20.1's patches, streaming sites in WebKit, Zen import, the new onboarding, the Arc-style pinned and group controls, and the app's internal rework. 0.2.40 is native API 13 and 0.2.41 is 20, so the control ran its own bench bundle, built from `git archive v0.2.40` (`dist/0.2.40/bench/main.jsbundle`). Measured on 2026-10-26, interleaved, display awake.

## Ratchet

The first candidate (a2ca6bdf) failed the ratchet with 59 counts over: tab switch selector calls 24085 → 48817, launch renders 996 → 2240 and commits 60 → 129, page load selector calls 56062 → 99463. The released exports of nightlies 1 to 6 placed two jumps, nightly.2 (per-row subscriptions and mounts for the icon fade, the WebKit mark, the pinned − control and press feedback) and nightly.4 (per-row glow setting and shortcut hints; the menu bar's revision re-rendered every row at launch). Fixed in 5b931ed5, ffab8b6a, a3bcc191, 65893a2a, ec498ed5 and bd360993; the remaining feature costs are raised by reason in 6ddaaca2. The candidate from 6ddaaca2 passed with 0 over.
