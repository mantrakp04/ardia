# 0.2.41 → 0.2.42 release gate

0.2.42 collects nightlies 1 and 2: page drags fixed, full screen under the menu bar, background tab sleeping, the Sync journal and its sealed passwords, the address bar's security changes, the onboarding that follows the browser you come from, and the profile-switch re-render fix. 0.2.41 is native API 20 and 0.2.42 is 21, so the control ran its own bench bundle, built from `git archive v0.2.41` (`dist/0.2.41/bench/main.jsbundle`). The candidates are CI's dry-run builds: RC1 from 15030118, RC2 from f6d71be3 (the release). Measured on 2026-10-27, interleaved, display awake.

## Ratchet

RC1 went over on 10 counts, all placed and raised by reason in 27ed657e: 2fd842a8's per-tab theme subscriptions (switchTabs selector calls and notifications), 48b52711's left-elided host label (small launch View mounts), 01100e5b's userinfo strip and `javascript:` check (the suggest micro counts), a window moved by macOS on a smaller display (small launch store keys), and open/close renders within their measured spread. RC1 then passed with 0 over on AC.

RC2 ran on battery, where the app skips its launch warm-up of recent tabs. RC1 on battery was the control: both went over on the same three counts with the same values (close device:onAnimatedValueUpdate 23, close renders 2356, typing timers 215) and nothing else. No ceilings were lowered from battery runs.

## JS

RC1, 3 alternating rounds, each app on its own bundle, on AC. Separated and worse: switch.medianMs 21.0 [20.7–21.1] → 22.3 [22.2–23.0] and hover24.otherJsMs 13.3 [13.1–13.4] → 14.1 [13.7–16.0]. Separated and better: profileSwipe renders 1417 → 1266, host updates 619 → 535, taskMs 122 → 114.

- **switch.medianMs** was 2fd842a8's theme selector, run on every store update twice per loaded tab. 18e80d22 reads it through one shared listener that wakes only when profiles, appearance or settings change. RC1 with the fixed bundle against RC1's own, on AC: 21.6 [21.5–21.7] → 18.4 [15.6–21.3].
- **hover24.otherJsMs** was the dev harness's 250 ms poll: every 0.2.41 run caught 9 ticks in the hover window, every RC run 10. Without the poll's time, the same reports read 9.6 [9.0–9.7] vs 9.5 [9.3–11.5], with identical commits, renders and host updates. f6d71be3 leaves the poll out of js-bench's taskMs and otherJsMs, as the idle rows and the ratchet already do. Users never run the harness.
