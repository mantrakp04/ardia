# 0.2.43 → 0.2.44 release gate

0.2.44 collects nightlies 1 to 7: the design tokens and shared controls, config files and hooks, the `ardia` command's control and `ardia browse`, shared folders, the emoji picker, the sidebar on the right, shared Top Apps per profile, the single glass pass for Top Apps, the swipe-back history list and the omnibox regex-stall fix. 0.2.43 is native API 35 and 0.2.44 is 47, so the control ran its own bench bundle, built from `git archive v0.2.43` (`dist/0.2.43/bench/main.jsbundle`; the build steps are below). The candidate is the local `scripts/release.sh 0.2.44` build (notarized, build 104). Measured on 2026-11-04, interleaved, on AC. The Mac was in use for most of the run, so the idle rows' "someone used the Mac" column is about 75 s per run.

## Ratchet

The first export went over on 25 counts in both runs. Six were waste and were fixed: e33cca7e8 (a Spinning wrapper around every icon button's glyph that no caller turns on, most of hover, switchTabs, open and typing growth), d50d6df36 (the Glass Dictate button re-rendered on every key; typing.renders 1734 → 1431), 910877ce8 (a second divider in the auto-hide toolbar's backdrop; switchTabs.mounts 494 → 468), a59a00600 (SidebarRowLabel memoized; hover.renders 768 → 720), 01f6dbf12 (keyword-provider scope work on every key with no providers; suggest.keys). 7e7780f0a raised 19 ceilings by reason (the sidebar row wrappers, the shared Text, ProgressTrack, Top Apps' glass group, the shared-folder mark, the emoji picker host, two early-returning store listeners, the linear host parse that replaced the stalling regex), and 8521df0d8 lowered 9. After the gate, 75e6fdb79 fixed a profileSwipe fan-out (below). The final build passes: `ratchet: ok`, 0 over, 69 below. A run during the release build and filming went over on four close counts: page events from the still-loading tabs reached the close window (7 extra commits, `event:topPageEvent` 12 against 0); the same build passed on a quieter Mac.

## JS

3 alternating rounds, each app on its own bundle. Separated worse in the gate: close.medianMs 12.2 → 14.4, close20.taskMs 349 → 398, close20.listenerMs 14.5 → 16.9, profileSwipe.taskMs 113 → 125, profileSwipe.renders 1301 → 1350. In three more alternating sets (against a tree bundle, the shipped bundle and the fixed bundle) none of the timing rows reproduced (close.medianMs 15.3 → 13.1, close20.taskMs 412 → 387 on the shipped bundle). The render count did: since the single Top Apps glass pass, PinnedTile passed a new badge element to TileFace on every render, defeating GlassFill's memo, so all 12 tiles re-rendered on a swipe. 75e6fdb79 memoizes it (profileSwipe.renders 1313 → 1261). Startup to first window 3040 → 2926 ms and history stringify 20.6 → 12.4 ms were faster.

## Field

The dashboard's perf rule flags memory on 0.2.43 against 0.2.42: median 3.0 → 4.3 GB. On the 182 copies that ran both, memory rose by a median of 50 % with the same tab count, from 54 % more renderer processes at the same memory each: Chrome's Memory Saver (0ff15657d, Balanced by default) keeps more tabs loaded than the sleep sweep it replaced (4 h, 1 h under a memory warning, 10 min when critical). 0.2.44's nightlies hold 0.2.43's level. The bench doesn't show it: its tabs aren't idle long enough to sleep. Launch, the omnibox and profile switching are the same or better in the field.

## The control bundle

```
S=~/ardia-scratch/bench-0243; mkdir -p $S/src $S/out
git archive v0.2.43 | tar -x -C $S/src
for d in node_modules apps/browser/node_modules packages/{core,shaders,import,ardiacore}/node_modules; do cp -Rc "$d" "$S/src/$d"; done
R=$S/src; N=$(command -v node); cd $R/apps/browser
"$N" "$R/node_modules/react-native-macos/scripts/bundle.js" bundle --entry-file scripts/perf/bench-entry.js --platform macos --dev false --minify false --bundle-output "$S/out/bench.js" --assets-dest "$S/out/assets" --config-cmd "'$N' '$R/node_modules/react-native-macos/cli.js' config"
apps/browser/macos/Pods/hermes-engine/destroot/bin/hermesc -emit-binary -O -out "$S/out/main.jsbundle" "$S/out/bench.js"
```
