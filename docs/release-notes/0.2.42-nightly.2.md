## New

- **Onboarding opens with the meadow from ardia.dev**: a sunrise in light mode, a moonlit night in dark mode.

## Fixed

- **The first launch after an update is no longer two to four seconds slower.** macOS checks a new version before it runs for the first time; Install and Relaunch now gets that check done while you wait for the restart, so the new window opens as fast as usual.
- **Switching profiles no longer flickers.** The window tint and the sidebar snapped back for a frame or two as the switch finished.
- **Renaming a group or tab ends when you click the empty sidebar**, keeping the new name, instead of staying open until a second click opened a new tab.
- **Onboarding's browsers fit in two rows of four again**, without scrolling.
- **Crash reports say what went wrong**, so crashes can be traced back to the code. They still carry nothing about you or your pages.
