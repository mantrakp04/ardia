## Fixed

- **Closing a window no longer closes tabs another window still shows.** With Share tabs across windows on, closing a window also closed the tabs of every profile the other window hadn't opened yet. They now move to the window you're still using, with their groups, splits and pages.
- **⌘W in a split closes only the pane you're in.** The other pane stays on screen as a normal tab. Close Split View in the pane's menu closes the whole split, and each pane in the sidebar row has its own close button.
- **Arc import brings split views and every pinned tab.** Splits arrive as splits, and pinned tabs that repeated another tab's page are no longer dropped.
- **Sync stops re-uploading your whole profile every 10 minutes.** While you browsed, each synced profile rewrote a full ~3 MB copy to iCloud over and over; it now writes one only once enough has changed.
- **Turning Auto-Hide Tabs off keeps the tabs shown.** A window could stay hidden after the setting was switched off, and hide again after scrolling, switching or closing a tab. Every window now follows the one setting.
- **Korean typing in the command bar.** After the first syllable, each new consonant stayed separate; syllables now compose as they do in page fields.
- **Calls can share a window or the whole screen.** Picking one used to fail; Ardia now asks for Screen Recording and says how to turn it on, and its own windows can be shared.
- **Add to Chrome no longer fails with "Image decode failed".** When the Web Store's icon can't be fetched, the install carries on with the default icon.
- **Extensions show in private windows.** Every extension allowed in Incognito appears, not only a few. Thanks, [@FedyaLight](https://github.com/mantrakp04/ardia/pull/1144).
- **Connect Calendar does something.** When macOS won't ask for access, Ardia opens the Calendars privacy settings and says why.
- **Chats no longer make the toolbar bounce.** With Hide toolbar while scrolling on, Discord's chat flipped the bar up and down as it loaded older messages.
- **Resizing a tiled window keeps up.** Dragging the divider between Ardia and another app lagged seconds behind; the window now follows the drag.
- **Translated text starts showing in under a second.** Each paragraph appears as soon as it's ready, on-screen text first, and one very long paragraph no longer holds up other tabs.
- **A selected tab near the bottom of a long list keeps its whole glow**, and the Downloads button sits evenly in the sidebar's corner.

## New

- **Pinch a Little Ardia window.** Spread to open it in the main window, pinch in to close it, as on a Peek.
- **A collapsed group keeps the tabs you opened from it.** They stay under its header until you close them, as in Arc; clicking the header hides them.

## Smaller

- Tab groups sit 3 pt inside their box on the right and bottom, and the group's name no longer lights up on hover or press.
- An untitled bookmark on the bookmarks bar shows only its favicon.
