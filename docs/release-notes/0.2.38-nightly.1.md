## New

- **Clear, as in Arc.** A "↓ Clear" at the end of the line above your tabs closes every unpinned tab at once; pinned tabs stay. The toast's Undo puts them all back where they were, groups included, and ⇧⌘K does the same from the keyboard.

## Fixed

- **Extension shortcuts work again.** A shortcut an extension sets, or one you set in chrome://extensions/shortcuts, does nothing in 0.2.37 and earlier. It now runs the extension's command or opens its popup, from a page or from the sidebar. Ardia's own keys like ⌘T and ⌘W stay Ardia's, and an extension's suggested key that clashes with an Ardia shortcut isn't taken unless you set it yourself.
- **Every shortcut in Settings can be rebound.** ⌘1–⌘9, the tab switcher, Quit, Close Window, Full Screen, the Edit items and the rest either weren't listed or couldn't be changed, and some kept firing on their old key after you rebound them. All of them take your key now, and Settings › Shortcuts links to the extension shortcuts.
- **The sidebar's media player only shows media you can hear.** X's feed, which autoplays muted videos, put a player card in the sidebar while you scrolled. Like Chrome's media controls, the card now waits for a video or song that plays with sound. Settings › Tabs › "Show media controls in the sidebar" turns it off.
