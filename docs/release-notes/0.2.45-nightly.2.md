## New

- **Drop a .crx anywhere in a window to install it.** The New Tab page, the toolbar and the History, Bookmarks and Downloads pages used to ignore the drop; now they all ask to install it, as a page or chrome://extensions already did.
- **Agents can drag and drop with `ardia browse`.** HTML5 drag and drop works through the `ardia` command, and a background tab it drives keeps drawing without switching your view to it. Your own drags in that tab stay yours.

## Fixed

- **The bookmarks page can clear a big import at once.** ⌘A did nothing there, so thousands of imported bookmarks had to go one at a time; now ⌘A selects the whole folder, ⌫ deletes it, and Undo brings it all back. A folder of a few thousand also opens without growing Ardia past 1.8 GB and crashing, which, with the tab restored, crashed every relaunch too.
