## New

- **Profiles can show icons instead of dots**, as in Arc. Turn on "Show profile icons instead of dots" in Settings › Profiles, then right-click the switcher at the bottom of the sidebar to give each profile a symbol or emoji. It starts on if you set Ardia up like Arc or Zen.
- **Little Ardia has back and forward buttons** beside the traffic lights.
- **A compact toolbar**: "Compact toolbar" in Settings › Appearance makes it 28 pt instead of 41, so a 16:9 video in web full screen fills a maximized window without black bars at the sides.
- **Clean up old tabs after any time you like**, down to the minute, with Custom… in Settings › Tabs.
- **Export your bookmarks** as an HTML file any browser can import, from Settings › General, Bookmarks › Export Bookmarks… or the command bar.
- **Drop a .crx file on the window to install an extension.**
- **"Allow User Scripts"** in Settings › Extensions, for extensions that ask for it, so Tampermonkey and other userscript managers can run their scripts.
- **⌘-scroll goes to the page first**, so maps and design tools that zoom with it work, and "Zoom with ⌘ and the mouse wheel" in Settings › Privacy & Security turns Ardia's own ⌘-scroll zoom off.
- **The pinned calendar's countdown can start 5 to 60 minutes before a meeting** (Settings › Calendar), and right-clicking the tile hides "Now" for a meeting you're skipping.

## Fixed

- **Switching tabs no longer flashes a blank page**, and neither does closing one with ⌘W. The page you leave stays up until the next one has drawn.
- **Sign in with Google popups show their page again.** Since 0.2.41 they came up blank, or black in Little Ardia.
- **Two crashes**: opening the Downloads panel, which crashed 0.2.42 for some people, and closing a tab that runs in WebKit (or stopping its camera or microphone) on macOS 14 and 15.
- **Tabs stay awake much longer**: 4 hours in the background instead of 20 minutes, as in Chrome's Memory Saver. A tab paused in the sidebar player never sleeps, and pressing Play on one that did reloads it and picks up where it left off.
- **The sidebar player is one row**: a long title scrolls instead of being cut off, and close and mute appear beside Play/Pause on hover. A video you paused before leaving its tab no longer gets a player.
- **Gmail's dark theme keeps a dark toolbar**, and the bookmarks bar takes the site's colour along with the toolbar.
- **Middle-click closes tabs** when the tabs are on top, as it does in the sidebar.
- **Reload shows in the sidebar from 210 pt wide**, the sidebar's address field looks like a field, and the space under Clear matches the space above it.
- **The page's frame is 9 pt on every side**, in every layout.
- **Choose Folder… in Settings › Extensions and Settings' back and forward buttons work on the first click.**
- **Tencent Video's VIP videos play**: the site opens in WebKit, whose FairPlay can play them, instead of showing a black screen.
