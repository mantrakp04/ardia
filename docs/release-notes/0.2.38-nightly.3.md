## New

- **The hidden sidebar is easier to catch.** With the sidebar hidden, the peek now stays out while the pointer is up to 24 pt past its edge, as in Arc, instead of sliding away the moment you leave it. Throwing the pointer past the window's left edge opens it too, which helps when the window is tiled with a gap or sits on the right half of the screen. Thanks, [@narasaka](https://github.com/mantrakp04/ardia/pull/11).

## Fixed

- **Global extension shortcuts respect Ardia's keys on every keyboard layout.** On layouts such as Dvorak – QWERTY ⌘, an extension's Global shortcut could land on the key Ardia uses for New Tab or Close, and one set while chrome://extensions/shortcuts was recording a key could stop working until a restart. Both are fixed, and so are reserved commands you've bound to an arrow or editing key.
