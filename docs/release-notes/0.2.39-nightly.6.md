## New

- **Arc-style themes.** Settings › Profiles › a profile › Theme now has a custom gradient next to the presets: up to three colours on a colour wheel, Intensity, Pass-through blur, Noise with four textures, and Light, Dark or Match System. The window repaints as you drag, and the theme syncs with the profile.
- **Bring a space's theme over from Arc.** Importing Arc spaces now sets each profile's theme to its space's, colours and all, including a separate dark look. "Import from Arc…" in the Theme section applies one space's theme to the current profile.
- **New tab can open the command bar, as in Arc.** Settings › Tabs › "New tab opens" › Command Bar makes ⌘T, File › New Tab and + New Tab bring up the command bar over the page instead of a New Tab page. No tab exists until you pick something, and Esc leaves everything as it was. The New Tab page stays the default.
- **Move to Pinned, and back, with ⌥⇧⌘D.** It moves the selected tabs into the pinned list, and a pinned tab back to where it was. It's in the Tabs menu and can be changed in Settings › Keyboard Shortcuts.
- **A pinned tab has one page across windows, as in Dia.** Opening a pinned tab in a second window moves its page there without reloading, video and all. The first window shows it greyed until you click it back.

## Fixed

- **Tabs and pinned tiles open on the first click.** A tile or tab clicked as its hover card appeared needed a second click, because the card took the first one while it faded in.
- **"Shared data" shows on every Mac.** A profile added from another Mac through Sync got data of its own, so Settings › Profiles hid its Shared data row. It now shares the same profile's data there too. A profile already added that way keeps its own data: remove it on that Mac and use "Add to This Mac" again.
- **Settings no longer opens blank.** The Settings and Import windows could come up empty until a relaunch.

## Smaller

- Dropping a tab just past the last pinned tile in the top tab strip no longer leaves it stuck.
