## Fixed

- **Saved passwords and cookies no longer vanish after a slow login.** If your login keychain hadn't shown Ardia's key yet when Ardia started, Ardia made a new key on its own, and every saved password and cookie stopped opening. Now Ardia makes a key only for a brand-new profile. Otherwise it waits a few seconds, then asks: quit and try later, or start over with a new key.
- **A key Ardia can't open gets a way out.** When the key is there but Ardia isn't allowed to use it, or it's damaged, Ardia says which and offers Try Again instead of quitting. It never replaces the key on its own.
