## New

- **Hooks**: rules in `~/.config/ardia/hooks.json` can rewrite or block links before they open (old.reddit.com instead of www.reddit.com, say), send links from a given app to a profile, file finished downloads into a folder, deny camera or microphone requests, or run a command or script when something happens: a launch, a tab going idle, the Mac waking. Anything that reaches outside the page you're on, like a folder outside Downloads or a program that decides, waits until you approve it in Settings › Advanced › Automation. `docs/automation.md` has the full list.
- **Your own address bar rows**: config.json can add rows to the address bar, from a fixed list, a URL template or a suggest endpoint, either behind a keyword (type it, then Space or Tab, as with a site search) or mixed in under the top results. Endpoints stay off until you approve them.

## Fixed

- **Picture in Picture in WebKit tabs** works, including for a video embedded in another site's player. The button did nothing before.
- **With the sidebar on the right**, the window buttons now move with it instead of staying at the window's top left, and the sidebar keeps the same 9 pt margin from the window's edge as from the page.

## Smaller

- The bundled uBlock Origin is now 1.75.4.
