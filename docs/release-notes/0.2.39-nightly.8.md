## Fixed

- **Sites signed with eMudhra's compromised certificates are blocked.** Eight eMudhra intermediate certificates were made with private keys anyone can work out from the certificates themselves, so anyone could have issued a certificate for any site through them. Ardia now refuses those eight, their copies cross-signed by Sectigo, and the emSign ECC Root CA - G3 they chain to, as Chrome, Firefox and Safari do. The block is built into Ardia, so it holds without waiting for a list download.
