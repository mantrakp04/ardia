## Fixed

- **⌘W closes the tab even with the find bar open.** With Find (⌘F) open, the first ⌘W only closed the find bar and a second one closed the tab. One press closes the tab now, as in Dia and Chrome; Esc still closes just the find bar. In Little Ardia, ⌘W closes the window the same way.
