## New

- **Sync carries your extensions.** With Sync on, a Chrome Web Store extension you install on one Mac installs on your others, with the same permissions you approved and the same on, private-window and toolbar-pin settings. Removing one stops it from installing on your other Macs; it doesn't remove it there yet. Settings › Sync › "Extensions" turns it off.

## Fixed

- **Certificate revocations and root updates arrive again.** chrome://components showed CRLSet at 0.0.0.0 with "Update error": Ardia never received Chrome's list of revoked certificates or its root store updates. It now fetches CRLSet, PKI Metadata and the SSL error assistant from Google over HTTPS, with no install ID, cookies or ping. No other component updates.
