## New

- **Share a pinned folder**: right-click it and choose Share Folder… to keep it in `iCloud Drive › Ardia Shared` and share it with macOS's own share sheet. No account needed. Links sync both ways, per profile, and open from Finder too.
- **A real emoji picker** for profile and sidebar icons: search, every emoji by category, and SF Symbols, with the current icon highlighted.
- **Share from the page menu**: right-click to share selected text, an image, a link (trackers removed) or the page. File › Share › Share… is now ⌥⌘S.

## Fixed

- **Names save when you click away**: clicking outside a text field ends the edit, so a profile name no longer needs Return.
- **The sidebar's address field on a New Tab page** goes straight to the page's own search box when ⌘L is set to open in the centre, instead of stacking a second box on top.
