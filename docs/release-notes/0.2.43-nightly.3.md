## New

- **Every right-click menu is rebuilt in Dia's order**: on a tab, Pin comes first, then opening, organising, bookmarks, copying and customising, with Close last. Menus show their icons again on macOS 27, each action has one name everywhere, and a shortcut shows only when it really does that item.
- **Move several tabs, or a whole group, to another profile or window** from their right-click menu.
- **Right-click the reload button** to turn the ad blocker off for a site or clear its cookies, and right-click a profile to rename it, change its icon or colour, or open its settings.
- **The New Tab row, the sidebar's top and its footer** open the sidebar menu on right-click, as in Dia.

## Fixed

- **The sidebar's address field is liquid glass again.**
- **Pressing a tab row no longer bounces.** The row stays put, as Dia's do.
- **The page menu matches Dia's on links and blank pages**: Save Link As… comes before Copy Link Address, Open Link as another profile is gone, and Forward shows greyed out when there's nowhere to go.
- **A cancelled Save As no longer leaves an empty download** in the downloads panel.
