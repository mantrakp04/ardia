## Fixed

- **A light custom colour keeps the sidebar readable in dark mode.** Tab titles, groups and icons on a light colour stayed white on light grey; they now turn dark, in the sidebar and in the top tab strip, as Arc draws them. On a dark colour the selected tab's title stays white, where 0.2.45 could turn it black. Settings › Appearance › "Adjust text to the colour" turns this off.
- **A group's colour shows without hovering.** A coloured group now keeps its tinted box at rest, whether you picked the colour from the menu or with `ardia groups create --color`. Neutral groups still show their box only on hover, as in Dia.
- **Report a Problem says what's missing.** Send no longer looks greyed out for no reason: pressing it outlines the empty field and says what to add. Preview lists what's attached inside the sheet instead of covering the recording options.
- **The `ardia` command shows its pill only while it drives Ardia.** Editing tabs and groups from the command line no longer flashes "ardia is controlling Ardia", and the pill now reads "The ardia command is controlling Ardia".
