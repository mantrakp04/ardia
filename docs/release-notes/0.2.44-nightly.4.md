## New

- **Sidebar on the right**: pick Right under the layout cards in Make it yours, in Settings › Tabs › Sidebar position, or with View › Sidebar on Right. Only the sidebar layout moves. The hidden sidebar peeks in from the right as well.
- **New-tab links can stay in Little Ardia**: turn on Settings › General › "Open new-tab links inside Little Ardia" and a link that would open a new tab loads in Little Ardia itself, so Back takes you back. It's off by default. Thanks, [@narasaka](https://github.com/mantrakp04/ardia/pull/344).
- **`ardia browse`** takes agent-browser's commands and runs them on the Ardia you have open, so an agent that knows agent-browser can use Ardia as it is. It needs "Let the ardia command control Ardia" turned on.

## Fixed

- **Expanding Little Ardia while a link is still loading** no longer leaves the tab stuck on a blank page. Thanks, [@narasaka](https://github.com/mantrakp04/ardia/pull/551).
- **The traffic lights in the peeked sidebar** respond to clicks and hovers again when the address bar is in the toolbar. Thanks, [@narasaka](https://github.com/mantrakp04/ardia/pull/771).
- **Tabs moved to another window** (Open in Ardia, Move to Window, a drop on another window) land where "New tabs open at" puts a new tab, and never inside a group. Thanks, [@daberni](https://github.com/mantrakp04/ardia/pull/730).

## Smaller

- A tab group's last row rounds its corners to match the group box.
- The bundled uBlock Origin is now 1.75.2.
