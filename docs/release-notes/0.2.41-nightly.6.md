## New

- **A setup code from the ardia.dev demo sets Ardia up the same way.** Try the layout, look and pinned apps in the demo, then paste its code on onboarding's first screen ("Have a setup code?") or in Settings › General. Search, privacy and telemetry stay your choice in the app.
- **Every browser in "Where are you coming from?" shows its icon** instead of a globe.

## Fixed

- **Deleting a profile removes its WebKit data too.** The streaming-site engine's cookies and storage for a deleted profile stayed on disk; they're now removed, and a deletion that can't finish right away completes at the next launch.
- **A camera or microphone prompt no longer comes back after you allow it.** Every download and permission event reached Ardia twice, so a second, identical prompt could follow the first.
- **A prompt a site withdrew no longer appears later.** A permission request from a tab that wasn't on screen yet could still show after the site had cancelled it.

## Smaller

- **Colours are consistent across the app.** One red for errors and destructive actions, Dia's menu hover on every row, Dia's separator everywhere, one ink on filled buttons, and one dialog shadow.
- **Ardia's insides were reorganised** into one set of building blocks for its screens and one way to talk to the engine, so fixes land faster. Nothing else should look or behave differently; if something does, that's a bug.
