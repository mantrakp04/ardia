## New

- **Bangs in the command bar.** Type "!gh react", "react !w" or just "!yt" and Return goes straight to that site's search, or to the site itself; the top row names the site before you press it. The list is Helium's (Kagi's bangs plus imput's), built in and refreshed at most once a day, never at launch and without cookies. Start with "?" for a plain search.

## Fixed

- **Next and previous tab work from DevTools and from pages that grab keys.** ⌃⇟, ⌃⇞, ⇧⌘], ⇧⌘[, ⌥⌘→ and ⌥⌘← switch tabs before the page or DevTools sees them, as in Chrome. Before, with DevTools docked and focused, or on a page that caught those keys, the tab stayed where it was.
- **The launch picture keeps the active tile's shadow.** The picture Ardia shows while it starts drew the selected pinned tile flat; it now lifts like the real one.
