# Ardia

A macOS browser with Dia's polish and Arc's sidebar, built on Chromium.

## Boosts

**Boost**:
A saved set of changes to how a site looks or behaves: colours, font, size, case, zaps, and optional CSS and JS. It belongs to one profile, applies to one main domain and its www variant, and can be switched on or off.
_Avoid_: Theme, skin, userscript, extension

**Zap**:
One hidden element on a boosted page, picked by clicking it. Each zap can be undone on its own.
_Avoid_: Block, hide rule

**Share code**:
A pasteable piece of text that carries a whole boost: its settings, title and optional author name. Importing it gives the same styling. A boost with JS can't be shared.
_Avoid_: Share link, export file

**Include subdomains**:
A boost's option to apply to every other subdomain of its main domain as well, such as dashboard.example.com. Off by default.
_Avoid_: Wildcard
